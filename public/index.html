인증 요청

GitHub 공개 저장소와 정확한 40자리 commit SHA만 입력하세요.

브랜치명이나 짧은 SHA는 사용할 수 없습니다.

HOW IT WORKS

정책 고정부터 독립 검증까지

  1. 01

    정책 고정

    요청 시작 시 활성 정책과 서버 전체 심사 항목의 버전을 고정합니다.

  2. 02

    안전한 정적 분석

    서버가 exact commit을 다시 수집하고 저장소 코드를 실행하지 않은 채 평가합니다.

  3. 03

    가스리스 서명

    모든 필수 항목과 고정 안전 조건을 통과한 결과만 EAS Offchain v2 형식으로 서명합니다.

특정 Git commit에 대한 정적 분석 및 서버 고정 심사 기준 전체의 통과 결과입니다.

블록체인 기록 없음

실제 배포 서비스 전체를 보증하지 않습니다.
