02 · PIPELINE ONE PINNED SNAPSHOT

입력부터 공개 검증까지
하나의 snapshot이 이어집니다

요청 시작 시점의 ACTIVE 정책을 먼저 고정합니다.

  1. 01입력Repository + SHA
  2. 02정책 고정Policy snapshot
  3. 03정적 분석Fixed evaluators
  4. 04서명EAS Offchain v2
